# Example usage

For a photo showing dappled sunlight, an old wall, and a cat walking through the courtyard:

Caption candidates that fit the style system:

- Under the dappled light, a little cat quietly passes by.
- Sunlight slips through the leaves as a little cat wanders past.
- A quiet cat crosses the courtyard between patches of afternoon light.

The final choice should be generated from the actual input image rather than selected from a fixed list.
